# BCLC 肝細胞癌 (HCC) 分期與治療決策計算機

這是一個基於 **BCLC (Barcelona Clinic Liver Cancer) 2022 年更新版** 以及 **EASL / AASLD 國際指引** 開發的互動式單頁網頁應用程式 (PWA)。旨在協助胃腸肝膽科醫師、腫瘤科醫師與臨床醫護人員，透過輸入患者客觀的檢驗數據與臨床表徵，快速且精準地推導出肝細胞癌分期、標準治療建議及預估預後。

## 專案特色

*   **自動化防呆運算**：捨棄讓使用者直接輸入 Child-Pugh 分數的做法，改為輸入各項原始檢驗結果（如膽紅素、白蛋白、腹水嚴重度等），由系統在背景即時運算 Child-Pugh 分數與分級，大幅降低人為計算錯誤的風險。
*   **整合最新國際指引**：嚴格遵循 BCLC 2022 決策樹邏輯，包含各分期的標準治療建議（如免疫標靶組合、TACE、RFA 或手術）與各分期的預估中位存活期 (Prognosis)。
*   **純前端端側運算**：採用 Vue.js 3 進行狀態管理與邏輯判斷，所有運算皆在裝置本地端完成，無後端資料庫串接，絕對保障病患隱私。
*   **響應式與 PWA 支援**：使用 Tailwind CSS 打造跨裝置友善的 UI，並內建動態 Manifest。支援在智慧型手機或平板上直接「加入主畫面」，如同原生 App 般於門診或查房時快速開啟。

## 醫學決策邏輯 (決策樹)

系統將綜合以下三大支柱進行分級評估：

1.  **腫瘤特徵 (Tumor Burden)**：
    *   腫瘤數量（單顆 / 2-3顆 / 多發性）
    *   腫瘤大小（≤2cm / 2-3cm / >3cm）
    *   大血管侵犯 (MVI) 與肝外轉移 (EHS)
2.  **患者體能狀態 (ECOG Performance Status)**：0 至 4 分。
3.  **肝功能保留狀態 (Liver Function)**：透過五項指標即時換算 Child-Pugh A、B、C 級。

### 分期輸出對應：
*   **Stage D (末期)**：最佳支持性療法 (BSC) / 肝臟移植評估。
*   **Stage C (晚期)**：全身性系統治療 (免疫組合療法或標靶藥物)。
*   **Stage B (中期)**：經動脈化學栓塞術 (TACE) 或評估轉換全身性治療。
*   **Stage A (早期)**：手術切除、射頻燒灼 (RFA) 或肝臟移植。
*   **Stage 0 (極早期)**：射頻燒灼 (RFA) 或手術切除。

*   `README.md`: 本說明文件。

## 部署與使用方式

本專案採用零相依性 (Zero Dependencies) 的純靜態架構，部署極為簡易：

1.  將 `hcc-bclc-calculator.html` 檔案上傳至任何支援靜態網頁代管的伺服器（例如：GitHub Pages、Vercel、AWS S3 或是醫院內部的 Web Server）。
2.  取得專案網址後，在手機、平板或電腦的瀏覽器中開啟。
3.  **安裝為 App**：在行動裝置的瀏覽器（Safari 或 Chrome）選單中，點選「加入主畫面 (Add to Home Screen)」，即可在桌面建立圖示，獲得全螢幕的沉浸式操作體驗。

## 聲明與免責條款

本互動網頁僅為臨床決策輔助工具 (Clinical Decision Support Tool)。肝細胞癌的實際治療計畫極為複雜，需考量病患之門靜脈壓力、剩餘肝臟體積、其他共病症及當地藥物給付規範。本工具產出之結果不應取代主治醫師及多專科團隊 (MDT) 的專業醫療判斷。
